# Sauleta Website Reference

Source site: https://sauletasvente.com/
Captured for future Codex sessions on 2026-08-13.

## Purpose

This note preserves what was learned from inspecting the live `sauletasvente.com` website, so a future session can quickly recover the visual direction, structure, content, and offerings without re-crawling from scratch.

## Global Site Character

- Business: `Saulėta` / `Saulėta. Švenčių namai`, a children's playroom and celebration studio in Kaunas.
- Language: Lithuanian.
- Builder/stack: Hostinger Website Builder, Astro-rendered pages.
- Tone: warm, clean, family-focused, event-studio oriented.
- Visual style: bright natural photography, soft pastel decor, balloons, children, studio interiors, table settings.
- Palette impression: mostly white backgrounds and black text, with pastel photo accents, especially pale blue, soft pink, cream/neutral decor, and occasional green/balloon colors.
- Typography: bold clean sans-serif navigation and headings; Google font references include Hammersmith One, Open Sans, and Roboto.
- Navigation: centered top nav overlays the hero image on desktop. Active nav item is underlined.
- Main nav labels:
  - Apie
  - Galerija
  - Paketai ir jų kainos
  - Maisto tiekėjai
  - Atsiliepimai
  - Kontaktai
  - Naudinga

## Layout Pattern

- Pages usually start with a full-width photo hero.
- Hero images use a dark overlay so black nav and large white titles remain readable.
- Hero page titles are uppercase, centered, large, and white.
- Main content sections are white, spacious, and aligned to a fixed-width grid.
- Body text is black/dark gray, generally centered in page sections.
- The site uses lots of vertical whitespace. Some pages have large blank gaps before content due to builder positioning.
- Photos are central to the site. They are not decorative extras; they carry the brand and proof of the venue.

## Useful Implementation Notes

- If recreating or redesigning, prioritize:
  - full-bleed photographic heroes
  - dark hero overlays
  - centered top navigation
  - large uppercase page titles
  - generous whitespace
  - image-heavy galleries
  - clean black typography on white
  - simple two/three-column desktop layouts
- Avoid turning it into a generic marketing landing page. The current site is a venue/service catalog with strong photographic proof.
- The brand signal is the bright, elegant, family celebration studio: children, balloons, white interiors, pastel decor, table settings.
- For accurate copy/pricing, re-check the live site before publishing because prices and package contents may change.
